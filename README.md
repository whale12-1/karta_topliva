# ЭкоАтлас SAF 🗺️✈️

Интерактивная карта России для анализа потенциала производства и потребления устойчивого авиационного топлива (SAF).

## 🛠 Технологии
*   **Frontend:** React, Vite, Tailwind CSS, React-Leaflet
*   **Backend:** Python, FastAPI, Uvicorn
*   **DevOps:** Docker, Docker Compose, Nginx

## 🚀 Как запустить (Docker)

Самый простой способ запустить проект — использовать Docker.

1. Убедитесь, что у вас установлены Docker и Docker Compose.
2. В корневой папке проекта выполните команду:
   ```bash
   docker compose up --build -d
