# Обновления интерфейса «ЭкоАтлас SAF»

## Что изменено

1. Во вкладке «Фильтры» добавлены две независимые группы выбора:
   - «Годовой объём потребления топлива» — дистанция и расход топлива;
   - «Доля покрытия спроса на топливо» — собственные дистанция и расход топлива.
2. Выбранная группа подсвечивается. Нажатие на её заголовок или изменение любого фильтра переключает карту и таблицу на соответствующий набор данных.
3. Для покрытия спроса фронтенд запрашивает существующий backend endpoint `/api/scenarios/coverage/{distance}_{fuel}`. Backend и исходный JSON с данными не менялись.
4. Вкладка «Итоговый рейтинг» продолжает использовать группу `rating`, вариант которой выбирается уровнем расхода топлива.
5. Таблицы и окраска регионов используют сортировку по убыванию: максимальный показатель — тёмно-зелёный, минимальный — красный.
6. Фоновая заливка регионов карты сделана светло-серой, морская область — сине-бирюзовой. Добавлены схематичные белые волны, два небольших корабля и анимированный самолёт с воздушным следом.
7. Карточка региона показывает население, объём SAF, годовой пассажиропоток, предотвращённые выбросы и место в текущем рейтинге.
8. Интерфейс адаптирован для узких экранов: фильтры складываются в одну колонку, боковая панель становится нижним блоком.

## Где находятся изменения

- `frontend/src/App.jsx` — независимые состояния фильтров, переключение fuel/coverage/rating, карточка региона и список рейтинга.
- `frontend/src/components/Map.jsx` — светло-серая карта, морской фон, волны, корабли, самолёт и отступы вокруг России.
- `frontend/src/index.css` — обновлённый дизайн интерфейса.
- `frontend/src/data/constants.js` — новая шкала цветов от тёмно-зелёного до красного.

## Запуск проекта

Из корневой папки проекта:

```bash
docker compose up --build -d
```

Либо запускать frontend и backend отдельно по инструкциям в основном `README.md`.

## Проверка

Проверена структура данных: 8 регионов, 9 сценариев потребления топлива и 9 сценариев покрытия спроса. В исходном архиве отсутствовали установленные npm-зависимости; их восстановление через `npm ci` не завершилось в доступное время, поэтому production-сборку Vite в этой среде подтвердить не удалось.
